7. MOCKUP APIs

POST /api/v1/mockups/preview
Auth: Bearer token
Input:
- header.Authorization: Bearer <jwt>
- body.templateId: Mongo ObjectId cua template, bat buoc
- body.print.placeholders: mang placeholder tu client, bat buoc
- body.surfaceKey: "front" | "back" | "neckLabelInner", tuy chon
- body.responseType: "json" | "binary", mac dinh "json"
- body.format: "png" | "jpeg" | "jpg" | "webp", tuy chon

8. GHI CHU DE FRONTEND GOI API
- Tat ca API can auth deu dung header Authorization: Bearer <jwt>
- Login/Register/Forgot-password request OTP deu can turnstileToken hop le
- Project API chap nhan ca payload moi: surfaces.front/back.canvasJson
- Project API cung chap nhan payload cu: frontCanvasJson va backCanvasJson
- Project API va Mockup API chap nhan surface "neckLabelInner"
- Upload asset dung multipart/form-data, field ten la file
- URL file upload tra ve dang /uploads/...
- Mockup assets he thong duoc serve qua /mockups/...
- Forgot password request OTP luon tra ve message chung de tranh email enumeration
- OTP reset password hien tai la ma 6 so, het han sau 5 phut, khoa sau 5 lan nhap sai
