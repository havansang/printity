PRINTITY MONGODB SCHEMA
ODM: Mongoose

1. COLLECTION: users
Model: User
Muc dich:
- Luu thong tin nguoi dung
- Ho tro nhieu auth provider tren cung 1 account

Fields:
- email: String, required, unique, lowercase, trim
- displayName: String, default null
- avatarUrl: String, default null
- authProviders: [String], enum ["local", "google"], default []
- passwordHash: String, default null
- google: Object, default null
- google.googleId: String, trim
- google.email: String, lowercase, trim
- google.emailVerified: Boolean, default false
- google.picture: String, trim
- lastLoginAt: Date, default null
- sessionVersion: Number, default 0
- passwordChangedAt: Date, default null
- createdAt: Date, auto by timestamps
- updatedAt: Date, auto by timestamps

Business rules:
- Neu authProviders co "local" thi passwordHash bat buoc phai co
- Neu authProviders co "google" thi google.googleId bat buoc phai co
- authProviders duoc loai bo gia tri trung lap truoc khi validate
- sessionVersion dung de vo hieu hoa toan bo JWT cu khi user doi password

Indexes:
- unique index: email
- unique sparse index: google.googleId

2. COLLECTION: passwordresets
Model: PasswordReset
Muc dich:
- Luu OTP reset password va trang thai resend/verify
- Ho tro chong spam, chong brute force va reset token mot lan

Fields:
- email: String, required, unique, lowercase, trim
- otpHash: String, default null
- expiresAt: Date, default null
- attempts: Number, default 0
- sendHistory: [Date], default []
- lastSentAt: Date, default null
- lockedAt: Date, default null
- consumedAt: Date, default null
- resetTokenHash: String, default null
- resetTokenExpiresAt: Date, default null
- createdAt: Date, auto by timestamps
- updatedAt: Date, auto by timestamps

Business rules:
- OTP la ma 6 so nhung duoc hash truoc khi luu DB
- OTP het han sau 5 phut
- 1 email chi gui toi da 1 OTP / 30s va max 5 OTP / 10 phut
- Sai OTP toi da 5 lan thi lock, user phai resend ma moi
- Khi verify dung, otpHash bi xoa va doi sang resetTokenHash de sang buoc doi mat khau
- Sau khi reset password thanh cong, document PasswordReset bi xoa

Indexes:
- unique index: email

- availableColors la danh sach mau frontend duoc phep hien thi/chon cho template
- templateImageUrl va printArea la data toi thieu de frontend editor co the hien thi surface
- editor.printArea la vung in trong he toa do SVG editor
- render.printArea la vung dat design trong he toa do anh mockup PNG
- Neu dung rect-based mapping thi editor.printArea va render.printArea nen dong dang hoac rat gan dong dang
- transformPolicy quy dinh cach backend hieu x/y/scale/rotation ma client gui len
- supportedSurfaces duoc suy ra tu cac surface thuc su ton tai neu khong truyen tay

Indexes:
- unique index: slug

4. COLLECTION: projects
Model: Project
Muc dich:
- Luu editor state cua 1 thiet ke cua user
- Luu raw payload client gui len va payload da normalize de backend render preview

Fields:
- userId: ObjectId, required, ref User
- name: String, required, trim
- templateId: ObjectId, required, ref Template
- productType: String, required, enum ["tshirt", "polo"]
- selection: Object, default null
- selection.colorKey: String, default null
- selection.colorLabel: String, default null
- selection.colorHex: String, default null
- selection.variantId: Number, default null
- selection.cameraId: Number, default null
- selection.blueprintId: Number, default null
- selection.decoratorId: Number, default null
- renderOptions: Object, default null
- renderOptions.size: Number, default null
- renderOptions.format: String, default null
- renderOptions.mockupMode: String, default null
- renderOptions.mirror: Boolean, default false
- renderOptions.printOnSide: Boolean, default false
- renderOptions.canvas: Boolean, default false
- renderOptions.fontColor: String, default null
- renderOptions.country: String, default null
- renderOptions.newEmbroideryColorPalette: Boolean, default false
- printPayloadRaw: Mixed, default null
- printPayloadNormalized: Mixed, default null
- surfaces.front: Object
- surfaces.back: Object
- surfaces.neckLabelInner: Object
- surfaces.<surfaceKey>.canvasJson: Mixed, default null
- surfaces.<surfaceKey>.previewImageUrl: String, default null
- surfaces.<surfaceKey>.designCompositeUrl: String, default null
- surfaces.<surfaceKey>.designCompositeWidth: Number, default null
- surfaces.<surfaceKey>.designCompositeHeight: Number, default null
- surfaces.<surfaceKey>.renderStatus: String, enum ["idle", "queued", "processing", "ready", "failed"], default "idle"
- surfaces.<surfaceKey>.renderHash: String, default null
- thumbnailUrl: String, default null
- status: String, enum ["draft", "completed"], default "draft"
- lastOpenedAt: Date, default Date.now
- lastRenderedAt: Date, default null
- createdAt: Date, auto by timestamps
- updatedAt: Date, auto by timestamps

Business rules:
- userId duoc lay tu JWT, khong lay tu client body
- productType la du lieu denormalized tu Template
- selection luu variant/camera/decorator ma user dang chon
- selection.colorKey la khoa on dinh de backend resolve mockup mau ao
- renderOptions luu options render nhu size, format, mockupMode, mirror
- printPayloadRaw luu JSON goc client gui len, phuc vu debug, replay va doi soat
- printPayloadNormalized luu payload da normalize theo rule noi bo cua backend renderer
- surfaces.<surfaceKey>.canvasJson duoc dung de mo lai editor
- surfaces.<surfaceKey>.designCompositeUrl luu anh design trung gian neu backend can cache render nhanh
- surfaces.<surfaceKey>.previewImageUrl luu anh preview da render xong
- surfaces.<surfaceKey>.renderStatus theo doi tien trinh render preview
- Front/back/neckLabelInner surface luon co structure on dinh trong DB
- Backend van chap nhan payload cu frontCanvasJson/backCanvasJson va map vao surfaces.front/back.canvasJson

Indexes:
- { userId: 1, updatedAt: -1 }
- { userId: 1, productType: 1, updatedAt: -1 }
- text index: name

5. COLLECTION: assets
Model: Asset
Muc dich:
- Luu metadata file anh user upload de dua vao editor

Fields:
- userId: ObjectId, required, ref User
- originalName: String, required, trim
- mimeType: String, required, trim
- size: Number, required
- storageType: String, default "local"
- path: String, required, trim
- url: String, required, trim
- width: Number, default null
- height: Number, default null
- createdAt: Date, auto by timestamps
- updatedAt: Date, auto by timestamps

Business rules:
- Chi owner moi duoc list/delete asset cua minh
- path la duong dan tuong doi trong uploads/
- url la public URL de frontend load truc tiep
- Chi cho phep upload mime type la image

Indexes:
- { userId: 1, createdAt: -1 }

6. QUAN HE DU LIEU
- 1 User co nhieu Project
- 1 User co nhieu Asset
- 1 Project thuoc 1 User
- 1 Project tham chieu 1 Template
- 1 Template thuoc 1 productType
